# TCETO — Brand System

> Sistema de design para o curso "Superávit de Produtividade: A Inteligência Artificial Aplicada à Execução Orçamentária".

---

## Filosofia da Marca

### Princípios Core

1. **Clareza Institucional**
   O design deve facilitar a compreensão rápida de dados complexos. Informação acima da decoração.

2. **Inovação Sólida**
   Equilíbrio entre a modernidade da IA e a solidez de um Tribunal de Contas. Uso de azuis profundos com elementos gráficos limpos.

3. **Didática Visual**
   Uso estratégico de diagramas e hierarquia tipográfica para guiar o aprendizado do aluno.

---

## Logo

### A Marca TCETO

O logo deve ser posicionado preferencialmente no canto superior direito ou inferior esquerdo dos slides, mantendo uma área de respiro de 20%.

**Arquivo do logo**: `skills/pptx-generator/brands/tceto/assets/logo.png`

**Regras de uso:**
- Não distorcer as proporções.
- Usar a versão em alta resolução.
- Em fundos escuros, utilizar a versão com contraste adequado (se disponível).

## Sistema de Cores

### Accent Principal — Azul Institucional

A cor de assinatura que representa autoridade e confiança.

| Nome | Hex | Uso |
|------|-----|-----|
| Azul TCETO | `#01467d` | Títulos, botões primários, destaques |
| Azul Vibrante | `#0078d4` | Links, estados ativos, ícones |
| Dourado Alerta | `#ffc107` | Pontos de atenção, alertas, ícones de destaque |

**Regra:** O Azul TCETO é o herói. Use para âncora visual. O Dourado deve ser usado com parcimônia para guiar o olhar.

### Base do Tema

**Tema Claro (Padrão)**
```
Background:     #ffffff
Background Alt: #f9fafb
Surface:        #f3f4f6
Text Primary:   #111827
Text Secondary: #4b5563
```

## Tipografia

### Fontes

- **Heading:** Montserrat — Sólida, geométrica e profissional. Usada para títulos e impacto.
- **Body:** Inter — Uma das melhores fontes para leitura em telas. Usada para todo o texto corrido.
- **Code:** JetBrains Mono — Fonte monoespaçada clara para prompts e códigos.

### Regras Tipográficas

| Elemento | Fonte | Peso | Tamanho |
|---------|------|--------|------|
| Display/Hero | Montserrat | 700 | 36px+ |
| H1 | Montserrat | 700 | 30px |
| H2 | Montserrat | 600 | 24px |
| Body | Inter | 400 | 16-18px |
| Code | JetBrains Mono | 400 | 14px |

---

## Elementos de Assinatura

O estilo visual do TCETO é focado em **Clareza e Estrutura**.

1. **Cards Limpos**
   Uso de superfícies claras (`#f3f4f6`) com bordas muito sutis (1px) para agrupar informações relacionadas.

2. **Diagramas Estruturados**
   Fluxogramas que usam o Azul TCETO para processos e o Dourado para decisões críticas.

3. **Espaçamento Generoso**
   Evitar slides "poluídos". O conteúdo deve respirar, seguindo a lógica de Feynman de que menos é mais quando se quer ensinar bem.

## Referência Rápida

### Quando usar o Azul Institucional

| Use Azul TCETO | Não use para |
|-------------------|-----------|
| Títulos principais | Longos parágrafos de texto |
| Ícones de marca | Mensagens de erro/cancelamento |
| Divisores de seção | Fundo de slides com muito texto |

### Uso de Fontes

| Montserrat | Inter |
|----------------|-------------|
| Capas e Títulos | Descrições e Bullet points |
| Botões e Labels | Notas de rodapé |
| Números de destaque | Tabelas de dados |
