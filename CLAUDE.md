# CLAUDE.md

Antes de qualquer tarefa, leia `AI_CONTEXT.md` e use seu conteúdo como contexto global do projeto.

As skills do projeto ficam na pasta `skills/`. Consulte e utilize as skills relevantes para cada tarefa.

Sempre que executar Python, use o ambiente virtual `venv` do projeto.

## Prioridade
1. Instrução do usuário  
2. `AI_CONTEXT.md`  
3. Skills em `skills/`  
4. `CLAUDE.md`

## Regras
- Releia `AI_CONTEXT.md` no início de cada sessão.
- Use skills compatíveis com a tarefa atual.
- Ao usar Python, ative/use `venv` antes de executar comandos.
- Se arquivos mudarem, considere a versão atual.
- Se não existirem, siga normalmente.
